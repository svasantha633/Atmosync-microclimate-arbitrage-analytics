# Contributing Guidelines

Thank you for your interest in contributing to the **AtmoSync Micro-Climate Arbitrage Analytics** project!

## How to Contribute
1. **Fork & Clone**: Fork this repository and clone it to your local environment.
2. **Branch Naming**: Create a feature branch following the project conventions (`feature/your-feature-name` or `name_branch`).
3. **Data Integrity**: Do not modify raw source dataset files directly. Use Python data cleaning scripts in `scripts/` or `clean_data.py`.
4. **SQL Standards**: Ensure all new SQL queries are standard SQLite compatible, well-commented, and placed under `sql/`.
5. **Pull Requests**: Submit a Pull Request targeting `main` with a concise summary of changes.
